# NOVA Netzwerk – statische Erstversion

## Veröffentlichung

1. Sichere die bisherigen Dateien aus deinem Repository.
2. Ersetze `index.html`, `styles.css`, `script.js`, `favicon.svg` durch die gleichnamigen Dateien aus diesem Ordner.
3. **Behalte deine vorhandenen `impressum.html` und `datenschutz.html` bei**, nachdem du sie auf Richtigkeit und Vollständigkeit geprüft hast.
4. Committe die Änderungen auf `master`. GitHub Pages aktualisiert die Website anschließend automatisch, sofern Pages bereits auf diesen Branch konfiguriert ist.
5. Prüfe https://mxrkus21.github.io/nova-website/ auf Mobilgerät und Desktop.

## Wichtig vor dem Teilen

- GitHub Issues im Repository müssen aktiviert und öffentlich beschreibbar sein. Teste die Links „Projekt vorschlagen“ und „Offene Projekte & Diskussionen“ mit einem separaten GitHub-Konto.
- Ein GitHub-Konto ist für Beiträge notwendig; Besucher ohne Konto können öffentliche Issues nur lesen.
- Drei Projektkarten sind ausdrücklich als **Projektideen** bezeichnet. Es existieren dadurch noch keine realen Projektgruppen.
- Die Plattform wird durch GitHub und dessen Moderations- und Nutzungsregeln begrenzt. Der Repository-Betreiber bleibt technisch für Issues zuständig; GitHub Issues ist **keine vollständig betreiberfreie Lösung**.
- Prüfe Impressum, Datenschutzerklärung und Moderationsregeln, bevor du öffentlich Besucher einlädst.
- Es wird keine Verbindung zu MrWissen2go behauptet.

## Später

Wenn NOVA mehr Beteiligung bekommt, ist ein echtes Forum (z. B. Discourse) oder eine dedizierte Beteiligungsplattform geeigneter. Derzeit gibt es keine Profile, direkte Nachrichten oder eigenständige Projekt-Workspaces.
