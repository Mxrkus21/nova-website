# ✳ NOVA Netzwerk

### Menschen verbinden. Ideen entwickeln. Zukunft gestalten.

**Die Zukunft ist nicht vorgegeben. Wir können sie gemeinsam gestalten.**

NOVA ist ein unabhängiger Ausgangspunkt für Menschen, die politische und gesellschaftliche Ideen nicht nur diskutieren, sondern gemeinsam weiterentwickeln möchten. Hier können aus Fragen Vorschläge, aus Vorschlägen Projekte und aus einzelnen Menschen Teams entstehen.

**[NOVA besuchen](https://mxrkus21.github.io/nova-website/) · [Projekte entdecken](https://mxrkus21.github.io/nova-website/projekte.html) · [Eigenes Projekt vorschlagen](https://github.com/Mxrkus21/nova-website/issues/new)**

## Warum NOVA?

Was wäre, wenn wir politische Möglichkeiten nicht nur aus bestehenden Angeboten auswählen, sondern selbst neue entwickeln?

Viele Menschen haben Ideen, andere bringen Wissen, Zeit oder praktische Fähigkeiten mit. NOVA soll ihnen einen gemeinsamen Ausgangspunkt geben: offen für verschiedene Perspektiven, transparent in der Diskussion und ohne vorgegebene politische Richtung.

Es geht nicht darum, dass alle derselben Meinung sind. Es geht darum, dass Menschen **miteinander denken, kritisch prüfen und eigenständig handeln** können.

## So funktioniert das Netzwerk

1. **Projekt entdecken:** Auf der [Projektseite](https://mxrkus21.github.io/nova-website/projekte.html) werden aktuelle öffentliche Vorschläge aus GitHub Issues angezeigt.
2. **Idee einbringen:** Erstelle ein [neues Issue](https://github.com/Mxrkus21/nova-website/issues/new) und beschreibe eine Frage, ein Problem oder ein Vorhaben. Ein fertiger Plan ist nicht nötig.
3. **Zusammenarbeiten:** Interessierte können im jeweiligen Issue diskutieren, Perspektiven ergänzen und ihre Mitarbeit anbieten.
4. **Selbst organisieren:** Die Beteiligten entscheiden gemeinsam, wie sie ihr Projekt weiterentwickeln und welche nächsten Schritte sinnvoll sind.

Für eigene Vorschläge und Kommentare wird derzeit ein kostenloses GitHub-Konto benötigt. Die NOVA-Website selbst hat keine Nutzerkonten.

## Was könnte daraus entstehen?

Zum Beispiel neue Modelle politischer Beteiligung, Konzepte für eine gerechtere Nutzung technologischen Fortschritts oder die Entwicklung einer unabhängigen politischen Organisation. Auch die Vorbereitung einer Parteigründung kann ein eigenständiges Projekt sein – **sie ist aber weder Voraussetzung noch das festgelegte Ziel aller Beteiligten**.

Die drei Projektimpulse auf der Startseite sind **Anregungen, keine bereits bestehenden Teams**. Du kannst einen davon aufgreifen oder einen völlig anderen Vorschlag machen.

## Was NOVA ist – und was nicht

NOVA ist **keine Partei, kein Parteiprogramm und keine politische Führung**. Die Plattform bietet einen Ort zum Zusammenfinden. Einzelne Projektgruppen verantworten ihre Ideen, Entscheidungen und Zusammenarbeit selbst.

NOVA ist ein unabhängiges Projekt, inspiriert von der Frage, wie politische Zusammenarbeit neu gedacht werden kann. Es besteht **keine offizielle Verbindung zu MrWissen2go oder dem inspirierenden [Video](https://youtu.be/ABonj-Rnrn4)**.

Offenheit bedeutet nicht Regellosigkeit: Beiträge sollen sachlich, respektvoll und rechtmäßig sein. Für die öffentlichen Diskussionen gelten auch die Regeln von GitHub.

## Technischer Aufbau

NOVA ist eine statische Website aus HTML, CSS und JavaScript, veröffentlicht über **GitHub Pages**.

- `index.html` – Startseite, Vision und Projektimpulse
- `projekte.html` – Übersicht öffentlicher Projektvorschläge
- `projects.js` – lädt offene GitHub Issues über die öffentliche GitHub-API
- `styles.css` – Design und responsive Darstellung
- `script.js` – Navigation und vorbereitete Projektvorschläge
- `favicon.svg` – NOVA-Symbol
- `impressum.html` und `datenschutz.html` – rechtliche Informationen

Die Projektübersicht ist **nur lesend**. Wer ein Projekt erstellen oder kommentieren möchte, wird zu GitHub weitergeleitet. Es gibt derzeit kein eigenes Backend und keine NOVA-Datenbank. Bei einem Ausfall oder einer Begrenzung der GitHub-API verweist die Seite direkt auf GitHub Issues.
